# Bible Party V3 — moteur de partie renforcé

## Modifications
- La durée choisie (20/30/45/60 min) devient un vrai chrono global de partie.
- Le chrono de 10 secondes est désormais réellement lié aux modes Défi 10 secondes et Time’s Up.
- Expiration du chrono : 0 point et passage contrôlé à la manche suivante.
- Verrouillage des réponses après validation pour éviter les doubles points.
- Bonus de série : +50 points à partir de la 3e bonne manche consécutive.
- `Qui suis-je ?` utilise maintenant le barème demandé : +300 / +200 / +100 selon l’indice utilisé.
- Le bouton principal est désactivé tant qu’une réponse valide n’est pas prête.
- Le bouton « Passer » est bloqué après validation pour éviter un double passage.
- Le résultat enregistre désormais chaque équipe dans le classement local, pas seulement le gagnant.
- Le projet reste compatible Expo Router / Expo SDK 57.

## Limite de validation
L'installation complète des dépendances n'a pas pu être terminée dans l'environnement de travail. Le code n'a donc pas été validé par un build Android/iOS réel.
