# Bible Party V69 — PWA iPhone / Web gratuit

- Version : 1.7.7
- Ajout du support PWA pour une utilisation installable depuis Safari sur iPhone.
- Ajout du manifeste web, des icônes PWA et de l'icône Apple Touch.
- Ajout des métadonnées Apple pour l'affichage plein écran depuis l'écran d'accueil.
- Configuration Expo Web statique avec `baseUrl` `/bible-party` pour GitHub Pages.
- Ajout de `web:export` pour générer la version web de production.
- La version Android native reste inchangée dans son fonctionnement.
- La PWA n'est pas une application iOS native : elle s'installe depuis Safari via « Ajouter à l'écran d'accueil ».
