# V35 — Premium Game Experience

Passe UI complète à partir de V34, sans changer la logique de jeu :
- nouvelle direction visuelle sombre premium, or discret et profondeur ;
- accueil plus spectaculaire et orienté lancement de soirée ;
- configuration tactile par cartes pour les modes ;
- hiérarchie renforcée sur l’écran de partie et les scores ;
- écran de victoire plus cinématique ;
- cohérence des cartes, boutons, espacements et contrastes ;
- fonctionnement et architecture V34 conservés.

## Vérification
- TypeScript : à lancer avec `npm run typecheck`.
- Web : `npm run web`.
- iOS : `npm run ios`.
