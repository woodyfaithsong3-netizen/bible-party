# Bible Party — checklist de publication

## Apple
- [ ] Compte Apple Developer actif
- [ ] App créée dans App Store Connect avec bundle id `com.bibleparty.app`
- [ ] Politique de confidentialité publique
- [ ] Nom, sous-titre, description, mots-clés
- [ ] Catégorie + classification d’âge
- [ ] Captures iPhone + iPad si nécessaire
- [ ] Icône 1024x1024
- [ ] URL de support
- [ ] Build TestFlight
- [ ] Test sur appareil réel
- [ ] Soumission App Review

## Google Play
- [ ] Compte Google Play Console
- [ ] Application créée avec package `com.bibleparty.app`
- [ ] Fiche Play Store
- [ ] Politique de confidentialité
- [ ] Classification du contenu
- [ ] Captures téléphone/tablette si nécessaires
- [ ] AAB de production
- [ ] Test interne
- [ ] Déploiement progressif

## Produit
- [ ] Toutes les questions vérifiées
- [ ] Aucun texte protégé utilisé sans droit
- [ ] Aucun contenu copié depuis JW.org
- [ ] Disclaimer indépendant visible
- [ ] Mode hors ligne testé
- [ ] Scores locaux testés
- [ ] Entraînement / erreurs / progrès testés
- [ ] Tous les modes de jeu testés
- [ ] Timer / pause / finale testés
- [ ] Accessibilité testée
